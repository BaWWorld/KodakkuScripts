## 糖豆人第二关画图

适用国服区域 1165。糖果柱机关与拳头机关默认提前 1.5 秒显示；持有黄色水晶时提醒提丰老师吹气，提醒开关和提前秒数可在脚本设置调整。金蝶跑圈仅绘制横杆预测，可通过用户方法「金蝶跑圈横杆预测」开关控制。斧头机关、跑圈糖果柱不绘制

当前版本：0.5.0.0。

## 糖豆人第三关画图

当前版本：0.3.0.0。作者：MYY。适用国服区域 1165。

糖豆人第三关画图，基于VFALLGUYS的AOE绘图数据进行编写，纯AI编写。

更新日志：尝试不再依赖循环绘图。尝试优化代码。

采用精简版的事件触发预警，取消常驻绘图节点和逐帧循环补画；包含 15 组、66 个机关范围，未同步机关不显示。第一组左右独立同步，每次自身结算事件安排下一轮预警，使用独立图名并在到期后自动销毁。

两组 `34802` 最多提前 1.5 秒显示，其他机关默认预览 2.5 秒。使用 VFX 倒计时填充，不透明度为 80%，关闭 Wave。脚本设置可调整 AOE 预览秒数及同步日志；同步方法隐藏。

回放暂停后，已安排的单次预警仍可能出现并到期，但不会通过定时器继续生成新的预警。使用本机 KodakkuAssist 0.6.0.1 编译通过，第一组间歇缺图修复仍需游戏内验证。
