## 糖豆人第二关画图

适用国服区域 1165。糖果柱机关与拳头机关默认提前 1.5 秒显示；持有黄色水晶时提醒提丰老师吹气，提醒开关和提前秒数可在脚本设置调整。金蝶跑圈仅绘制横杆预测，可通过用户方法「金蝶跑圈横杆预测」开关控制。斧头机关、跑圈糖果柱不绘制

当前版本：0.5.0.0。

本版沿用原版机关位置、尺寸和朝向；每次结算事件只安排下一轮预警，不再自行循环补画。危险区和横杆不透明度为 80%。

糖豆人第二关画图，包含搬水晶相关危险区预测和提丰老师吹飞预警，金蝶跑圈仅做了横杆预测。纯AI编写，反馈请到GITHUB或者你能找到我并私聊我。
