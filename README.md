## 糖豆人第二关画图

适用国服区域 1165。糖果串机关与拳头机关默认提前 1.5 秒显示；持有黄色水晶时提醒提丰老师吹气，提醒开关和提前秒数可在脚本设置调整。金蝶跑圈仅绘制横杆预测，可通过用户方法「金蝶跑圈横杆预测」开关控制。斧头机关、跑圈糖果柱不绘制，无自动移动功能。

当前版本：0.4.0.0。
