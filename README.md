## 糖豆人第二关画图

适用国服区域 1165。糖果柱机关与拳头机关默认提前 1.5 秒显示；持有黄色水晶时提醒提丰老师吹气，提醒开关和提前秒数可在脚本设置调整。金蝶跑圈仅绘制横杆预测，可通过用户方法「金蝶跑圈横杆预测」开关控制。斧头机关、跑圈糖果柱不绘制

## 糖豆人第三关画图

当前版本：0.2.0.3。作者：MYY。适用国服区域 1165。

糖豆人第三关画图，基于VFALLGUYS的AOE绘图数据进行编写，纯AI编写。

基于 legacy 版的持续绘图节点，包含 15 组、66 个机关范围。灰色未同步范围和 2.5 秒预览沿用该版默认值，参数固定在脚本内部，不显示用户设置；两个同步方法也隐藏。已移除开发诊断日志和未使用的高度资料。

此版本保留 legacy 的本机时间循环预测，录像暂停时相位仍会推进。使用本机 KodakkuAssist 0.6.0.1 编译通过；三份已有记录共 1,461 条事件的模型对照通过，尚未完成游戏内实测。
